# 2026-08-19

## PoE 1 / PoE 2 split

Added a persistent PoE 1 / PoE 2 selector to the header, immediately left of
the league picker. PoE 1 keeps the existing tools; PoE 2 opens an isolated
workspace ready for its first feature.

New shared game switching, data-path and versioned storage helpers live in
`src/shared/`. New game-specific features go under `src/games/poe1/` or
`src/games/poe2/`. Market snapshots are now namespaced under
`public/data/<game>/`; the PoE 1 fetcher reads the old deployed path as a
one-deploy migration fallback so accumulated history is preserved.

JSON remains the static snapshot format. Small user settings can use the
game-scoped storage helper; large mutable datasets should use IndexedDB or a
server database rather than `localStorage`.

History retention is now 430 days (about 14 months). The latest 72 hours stay
hourly and older points become daily, which comfortably holds two 3–5 month leagues without
making the browser download every raw hourly sample.

## Repository navigation

Completed the structural split rather than leaving the old PoE 1 files at the
source root. `src/app/` now only boots and selects a game; `src/shared/` holds
game-neutral infrastructure; and PoE 1 is grouped by catalogue plus feature
folders under `src/games/poe1/`. Each feature keeps UI, pure calculations and
curated data together. PoE 2 has its own shell and a clear
`features/<feature>/` destination.

The PoE 1 fetcher, feed adapters and diagnostics now live under
`scripts/poe1/`; tests mirror that ownership under `scripts/tests/poe1/`.
Added a root `AGENTS.md` with the short project map, dependency boundaries,
data locations and validation commands for future maintainers and agents.

## Gem change windows

Gem Levelling now shows the selected profit-change window beside the Trend
column. With Divine-adjusted enabled, the percentage uses the historical
chaos-per-Divine rate at both ends of the window. Expanded gem charts now carry
that rate history too, so they show the Divine-rate line and report adjusted
changes when a range is selected.

## PoE 2 boss profit

Added a PoE 2 Overview as the default landing tab. It follows the PoE 1 daily
briefing structure with a feature signal, decision desk and data-quality row,
but currently exposes only the native Boss profit tool. The responsive overview
is ready to accept future PoE 2 tabs without importing PoE 1 feature code.

Added the first native PoE 2 feature: a Boss profit tab with 21 encounter
variants across pinnacle, trials, league bosses and four Anomaly maps. It shows
gross EV, entry cost and net EV per kill. Added custom named TTK profiles so a
user can enter seconds or `m:ss` per encounter and see profit/hour. There is no
default profile or hidden fallback time; blank encounters remain EV/kill only.

Community/wiki percentages supplied in the screenshots are modelled separately
from inferred values. Every non-fixed chance and market price now switches to a
manual editor when clicked, while the normal table remains compact. Reset
restores the curated rate or pipeline price. The table retains `Adds to EV` and
the pool header retains combined EV so both levels of the calculation are visible.
The former rate-review banner and filter were replaced by live market-price
coverage: missing entry/drop items are listed and the panel clears as pipeline
or manual prices fill them. Corrected Uber Arbiter entry to the Faded, Ancient
and Weathered Crisis fragments; Depleted Mana Rune now prices through its
Runeseeker's Call conversion. Simulacrum's two Megalomaniac variants use the
normal poe.ninja quote as a visibly conservative Gamble floor. Six Omens removed
in 0.5 and Atziri's unpriceable rare Sacrificial Regalia no longer enter EV.
Anomaly names and the two sampled pools match the supplied map screenshots;
Derelict Mansion and Sealed Vault weights remain provisional.

Added an isolated PoE 2 price snapshot job with GGG's completed hourly trades
first and poe.ninja's PoE 2 exchange/stash endpoints as coverage fallback. It
stores current Exalted-denominated prices for the challenge league and Standard
under `public/data/poe2/`; small rate/price overrides remain in the game-scoped
browser store. PoE 2 stash prices now respect `core.primary` and convert Divine
quotes to Exalted with the response's own rate; this fixes tiny values such as
Hateforge's `0.5766 Divine` being displayed as `0.58 Exalted`. PoE2Scout now
fills only the names left unpriced by both sources. External price requests now
time out instead of allowing one stalled category to block the entire snapshot.

Reworked the PoE 2 Boss profit page around the PoE 1 layout: a scrollable,
color-coded boss ranking stays on the left while the selected encounter's EV,
TTK and drop pools stay on the right. Text and table sizing now matches the PoE
1 pages more closely, and Uber encounter names use the `Uber <boss>` form.
Bosses can carry multiple filterable group tags, including Atlas, Ritual and
Delirium secondary memberships. Added a global reset for manual rate and price
overrides without deleting TTK profiles. The PoE 2 boss workspace keeps its
dense ranking/detail layout, while both games now compose one shared header,
tab bar and market-source strip. Shared UI tokens keep page gutters, header
height, titles, labels, controls, tabs and source text at the same scale; drop
tables still reflow inside their cards without nested horizontal scrollbars.
Drop info markers sit directly beside the item name at narrower desktop widths;
rarity and price-proxy labels remain on their own lines below it.

## PoE 1 history recovery

Fixed the post-split deployment readers to restore accumulated history,
backfill, previous prices and catalogue snapshots from
`/data/poe1/<league>/`. They had still been reading only the old unscoped path,
which made scheduled snapshots restart the stored curves. The old location
remains a migration fallback, and the Scarabs page can display the legacy
`history.json` filename when a dataset predates `scarabs-history.json`.

Recovered the pre-loss histories from GitHub Pages artifact `9370348078` and
merged them with the newest deployed points. Allflame now has 125 scarab
series and 11,208 plotted scarab points through league day 24.87. The new
pipeline produced the current Allflame snapshot and remains the source for all
future hourly updates; the artifact is only a recovery seed.

Checked-in history seeds now merge safely with deployed history during either
a code-only reuse or a fresh data fetch. Added a 30-second external JSON
request timeout after a Hardcore fallback remained open indefinitely during
the recovery refresh.
