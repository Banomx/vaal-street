# 2026-08-08

- Made Depth EV the default Biome targets view and promoted its community-estimate explanation above the biome cards.
- Set the Delve per-node fossil baseline to current in-play counts: 1 special fossil per biome node (was 3). Assumption help text updated to match — it no longer cites guide figures it isn't using.
- Fossil nodes are now special-or-stash: the separate "generic fossil node" type is gone, so Depth EV blends the special target against a stash (84% of fossil nodes at depth 300, 10% at the 1500 cap). Old sample profiles fold their generic observations into the stash counts on load.
- Smuggler's Stash loot excludes the six biome-target fossils and any fossil reachable only behind a fractured wall — 15 fossils in the pool. Both exclusions are unconditional, so the wall toggle no longer touches the stash.
- Fixed fractured walls to be per biome, per the wiki: Shuddering (Frozen Hollow) was missing entirely, and the `openWalls` toggle now filters per biome, so Fundamental leaves Magma Fissure's pool but stays in Sulphur Vents'. The Fractured Walls pool asks the coarser question — can a wall hand you this anywhere — so it holds all five, Fundamental included. Biome pools were verified against the wiki list and all seven match.
- Reworked Smuggler's Caches into **Smuggler's Stash**, renamed everywhere in the UI. It is no longer a per-biome figure: `computeStash` prices one pool for the whole mine and carries a 4–10 count range instead of a flat quantity. It renders as a card inside the Biome targets grid, sorted with the biomes under whichever view is active, opens into a panel listing its 15 pool fossils with live prices, and scores under Opportunity as stash share × median stash — leading the grid at shallow depth and still holding a score at the 1500 cap.
- Contested prices (the ones carrying a `volatile` tag) now fall back to poe.ninja when nothing traded settles them and no active price was available. Exempt: GGG, poe.watch exchange rows with real volume, and anything the active price already fixed. Full order for a boss line is GGG → poe.watch active price → poe.ninja when contested → poe.watch listing floor.
- Boss and Delve drop prices now use poe.watch's **active price** where it exists — the figure from their beta pricing panel, which reflects what is clearing rather than the cheapest ask. The Untouched Soul goes from a 20c floor (50c mean) to 9c. Undocumented endpoint, one request per item, so it runs only for configured boss names on the primary league, capped by `WATCH_BETA_LIMIT`, and any failure falls back to the floor.
- Boss drops are now quoted as the item a boss hands over: the unidentified market first (labelled `Unid`), else the poe.watch listing floor rather than the mean. The floor is shown unlabelled — it is the right figure, and a badge would read as a warning about it when the mean is what overstated boss profitability. GGG completed trades and `@synthetic` averages are exempt. Entry costs follow the same rule: the GGG price when the digest carries the name, otherwise the poe.watch floor rather than the mean. Expect boss EVs to fall — the mean was pricing well-rolled copies nobody is given.
- Volume now only disqualifies a poe.watch row for being *expensive*. A dead Unidentified Glorious Vanity ask at 61.5 million chaos was pricing the item because `lowConfidence` only tagged it, but requiring volume outright was too strict — it also threw away cheap thin rows, and each one dropped pushed the quote up. An untraded row is kept when it undercuts everything that moved and dropped when it sits above. An all-untraded name still keeps its floor, and genuinely dear traded markets are untouched.
- Corrupted rows can no longer be the drop price (`isWatchBaseVariant` rejects `gemIsCorrupted`). Limited reach: `gemIsCorrupted` is the only corruption field in poe.watch's `ItemData` and the docs scope it to gems, so a corrupted unique is indistinguishable at row level, and the beta endpoint's `corrupted` parameter is inert — `any`, `false`, `no`, `true`, `0` all return identical payloads (activePrice 9, 396 samples), so the active price can't exclude corrupted listings either. The unidentified-first rule is what actually keeps corrupted copies out of a boss quote.
- Added cross-feed price checking (`src/priceCheck.js`): every name both poe.watch and poe.ninja know is compared on the floor — the same statistic boss lines quote, since comparing means flagged items over a number the site never shows — both figures recorded, and anything 1.5x or more apart is recorded. The badge only appears while the disagreement is still open — a traded price or an active price settles it, and warning there would flag a correct price while quoting two figures neither of which is shown. Where it is open it reads `contested` and the tooltip names both figures and which one the line uses. The hourly log prints the widest gaps. Nothing is overwritten — it is a confidence signal.
- Added a routing FYI at the top of the Bosses view: a boss with no road attached can still be reached — nodes around it with only 2 or 3 connected roads are the ones that can hide a fractured wall.
- Kurgal's Zorath's Eye line now prices **Zorath's Eye of the Inevitable** alone — the other three variants come from unrelated content. The `@zorath-eyes` synthetic is retired, so the hourly run stops chasing prices for three items this boss never drops.
- Biome panels now list only the named node's own fossil — it drops nothing else, and the biome's wider pool belongs to the stash and wall cards. Depth EV availability now keys off the target and the stash rather than the biome pool, so an unpriced biome list no longer blanks a figure the stash can supply.
- Dropped the per-biome Smuggler's Stash row from the biome breakdown table. The stash has its own card, and repeating its value under every biome said nothing about the biome. The Depth EV row still blends against it.
- Delve pool lists are now ordered dearest first with unpriced fossils last, in the engine, so the biome and cluster panels both get it. They were alphabetical.
- Added a **Fractured Walls** card to Biome targets: 15% of nodes travelled to, 4–6 fossils, pool is the five wall fossils. Preliminary drop count. Shares one `clusterNode` model with the stash, so both rank, open and chart the same way.
- Both cluster cards now open a panel with the fossil price chart the biome cards have — the stash panel had no graph before.
- Biome target cards now all share one height (`grid-auto-rows: 1fr`) with the estimate line pinned to the bottom, so wrapping node names no longer make the grid ragged. Also gave `.dl-biome-head` `box-sizing: border-box` — the class assumed a button, so the stash card's plain div overflowed and clipped its value. Stored sample keys stay `cacheNodes`/`cacheFossils` so existing logged profiles survive.
